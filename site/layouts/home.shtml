Why Oriel

Everything a desktop app needs, compiled in only when you ask for it.

Small and fast to build

A release app is a few MB. The build cache is hundreds of MB, not gigabytes, and Zig rebuilds incrementally.

Typed both ways

Write Commands and Events as plain Zig structs. invoke and listen are generated for TypeScript at compile time.

Secure by default

Navigation limits, per-origin command capabilities, a strict CSP, and a bridge injected only into your own pages.

Batteries, opt-in

Tray, updater, SQLite and sqlite-vec, dialogs, notifications, global shortcuts, clipboard, file watching, media server.

Local AI built in

llama.cpp and whisper.cpp as modules, with a CUDA backend on Linux. Live captions run on the GPU in the ghostpen-lite example.

Ship it

oriel package builds deb, rpm and AppImage. Windows setup.exe installers build on Windows or cross-compile from Linux.

One struct, both sides

A pub fn in Commands is callable from the page. Its arguments and return type become the TypeScript types.
