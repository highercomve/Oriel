Security hardening, part 1
Origin-bound IPC tokens (other-origin frames can’t call commands), security.freeze_prototype, and security.headers (COOP, COEP, Permissions-Policy, …).

Security hardening, part 2 (v0.6.0)
The isolation pattern (a sandboxed frame hook signs every IPC call with an HMAC key the page never sees), CSP hashes for inline scripts and styles (strict_styles), and macOS Developer ID signing and notarization in oriel package.
